# 취쥐직

첨부 UI와 PRD를 바탕으로 구현한 직장 적합도 평가 사이트입니다.

## 실행

`dist/index.html`을 브라우저로 열면 설치 없이 사용할 수 있습니다.

Node.js가 있다면 프로젝트 폴더에서 `node preview.cjs`를 실행하고 http://127.0.0.1:4173 에 접속할 수 있습니다.

## 기능

- 단일 화면을 버튼으로 이동하는 4단계 평가와 항목별 상세 팝업
- 회사·근무지·거주지·급여·통근시간·환승 횟수 입력
- 7개 평가 항목 선택과 가중치 직접 입력 / 슬라이더
- 가중치 합계 검증과 100% 자동 재배분
- 항목당 3문항의 5점 척도 설문
- 점수 = (응답 평균 − 1) ÷ 4 × 100
- 종합 적합도 = 선택 항목 점수의 가중 평균
- 종합/항목 점수, 가중치, 비교 회사 점수, 후기 평점·개수·근속 기간 직접 수정
- 모든 화면 상단의 ‘모든 수치 수정’에서 일괄 편집
- 점선이 표시된 숫자를 눌러 개별 편집
- 자동 점수 복원 및 JSON 결과 내보내기
- 현재 탭의 sessionStorage에 입력값 저장
- 모바일/데스크톱 반응형 화면

비교 회사 및 내부 의견은 예시 데이터이며 실제 후기 서비스와 연결되지 않습니다. 외부 공식자료 링크는 참고용이며 제공된 PRD의 통계 수치를 검증된 사실로 사용하지 않았습니다.

기본 척도(1~5), 환산 기준(100점), 화면 단계 번호는 계산 규칙과 안내입니다. 사용자 입력 데이터 수치는 직접 편집할 수 있습니다. 직접 입력한 결과 점수는 설문 계산값보다 우선하며 ‘자동 점수 복원’으로 해제됩니다.

외부 라이브러리 설치가 필요 없는 HTML/CSS/JavaScript 구성입니다. Google Fonts에 접속할 수 없는 환경에서는 시스템 글꼴로 표시됩니다.

## 확인한 동작

- JavaScript 문법 검사
- 실제 브라우저에서 5단계 화면 이동
- 가중치 합계 오류 시 진행 차단 및 100% 자동 조정
- 21문항 전체 4점 응답 시 종합 75점 계산
- 항목 점수 92점 직접 수정 시 종합 점수 반영
- 후기 수 250건 변경과 저장 반영
- 390px 모바일 화면 가로 넘침 확인

## 배포 상태

공개 사이트: https://sjbrotherjs.github.io/team3/ (로그인 없이 접속 가능). 팀 GitHub 저장소 sjbrotherjs/team3에서 소스를 관리합니다. codex/chwiijikgak-site 브랜치의 docs 폴더가 GitHub Pages에 배포됩니다. dist 수정 후 docs에도 동일하게 반영해야 합니다. 회사 주소·고용24 채용·OpenDART 조회 코드를 추가했습니다. 실제 조회에는 로컬 서버의 .env에 전용 API 키를 설정해야 합니다. 공개 GitHub Pages는 정적 사이트로, 별도 API 서버 URL을 연결하기 전에는 실시간 조회를 제공하지 않습니다.

## 로컬 전용 API 실행

1. `.env.example`을 `.env`로 복사합니다.
2. 카카오 REST API 키, 고용24 키, OpenDART 키를 각각 입력하고 저장합니다. 키 값은 GitHub·채팅에 올리지 마세요.
3. `start-local.cmd`를 실행하거나 `node server.cjs`를 실행합니다. Node.js 20 이상이 필요합니다.
4. http://127.0.0.1:4174 를 엽니다. 키 변경 후 서버를 재시작해야 합니다.

회사명 아래 주소 찾기 → 실제 사업장을 선택하면 근무지에 주소가 입력됩니다. DART는 동일 이름의 법인과 지점을 혼동하지 않도록 법인 선택 후 연도·연결/별도를 지정합니다. 고용24는 사업자등록번호로 정확히 조회하며, DART 기업개황에서 사업자등록번호를 가져올 수도 있습니다.

`data/`에는 조회 시점부터 수집한 공고·급여 이력이 저장됩니다. 과거 전체 채용 이력을 소급 복원하거나 개인의 지원 횟수를 조회하는 기능은 아닙니다. 급여는 원문의 월급·연봉·시급 구분을 유지합니다.

DART는 사업보고서의 매출액·영업이익·당기순이익·부채총계·자본총계를 조회하고 매출 증감률·영업이익률·부채비율을 계산합니다. 원본 공시 수치는 편집 가능한 개인 평가 점수와 구분하며 공시 링크·연도·통화·연결/별도 기준을 표시합니다. 미공시·자료 누락·음수/0 분모는 임의로 수치를 생성하지 않습니다.

지도 교통수단 구분은 현재 수동 선택입니다. 실제 경로 자동 계산은 아직 구현하지 않았습니다. 자가용·도보·지하철은 각 지원 API를 연결해야 하며 동일 정확도를 보장할 수 없습니다.

OpenAI 키 입력·생성형 AI 기능은 포함하지 않습니다.

실제 키를 사용한 제공기관 통합 테스트는 아직 수행하지 않았습니다. `node --test server.test.cjs`로 재무 계산·XML 파싱·서버 키 분리·이력 중복 처리·설정 파일 접근 차단 테스트를 실행합니다.
